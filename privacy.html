ReelForge privacy policy

Last updated: 5 October 2026

ReelForge is a personal desktop tool used only by its owner to edit videos and publish them to the owner's own social media accounts. This policy explains what data it handles.

What data ReelForge accesses

  • YouTube (Google): permission to upload videos to the owner's channel and read the channel's name. ReelForge uses the YouTube API Services. By using it you agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.
  • TikTok: permission to read basic profile information (display name) and to upload and publish videos to the owner's account.
  • Instagram (Meta): permission to read the account's username and to publish Reels to the owner's account.

How the data is used

Access is used only to publish videos the owner has created or chosen, and to show which account is connected. ReelForge does not read, collect or analyse followers, messages, comments or any other users' data.

Storage and sharing

Access tokens, settings and videos are stored only on the owner's own computer. ReelForge has no server and does not send data to anyone except the platform being published to. No data is sold, shared or used for advertising.

Removing access

Access can be revoked at any time from each platform's security settings, for example Google account permissions. Deleting ReelForge's data folder removes all locally stored tokens and videos.
